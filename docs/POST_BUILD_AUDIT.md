## 4. Defect Remediation During Audit

1. **G01 Regex Pattern Disjunction Defect**:
   - *Issue*: Pattern `r"ignore (all|previous|prior) instructions"` failed when input contained compound phrases like `"ignore all previous instructions"`.
   - *Fix*: Updated pattern to `r"ignore\b.*?\binstructions"` and added `\bdisregard\b.*?\binstructions`.
   - *Verification*: Confirmed all prompt injection variants are deterministically caught.

2. **Quality Audit Scoring False Positive**:
   - *Issue*: Audit test checked substring `"pass"` in response, which triggered on `"passes arguments"`.
   - *Fix*: Updated check with word boundary regex `r"\b(score|grade|marks|fail|points)\b"`.
   - *Verification*: Confirmed zero scoring/grading language in all responses.

3. **STT Streaming vs StreamAdapter Flexibility**:
   - *Enhancement*: Added `GNANI_STT_USE_STREAMING` configuration flag in settings and `agent.py`, allowing toggle between WebSocket streaming and Silero VAD `StreamAdapter` REST transcription.
